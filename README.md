# Gravity Shift

重力を上下に反転させ、床と天井を行き来しながら進む2D横スクロールアクションゲームです。
移動、ジャンプ、ダッシュ、射撃に重力操作を組み合わせ、敵の攻撃回避、ルート選択、
ステージギミック、ボス戦のすべてで重力方向を活用します。

## 主な特徴

- 床と天井を切り替える重力反転アクション
- 射撃、ダッシュ、レーザーを組み合わせた戦闘
- 重力ブロック、ループ穴、ノコギリ、チェックポイントなどのギミック
- 重力の影響を受ける敵と、独自に行動する敵
- 自身の重力を切り替えながら戦う中ボス・大ボス
- キーボードとゲームコントローラーの両方に対応
- タイル、敵、ギミック、カメラ範囲、ボスを配置できる専用ステージエディター
- Undo・Redo、配置検証、ステージサイズ変更に対応した編集機能

## 開発環境

- C++
- Visual Studio 2022
- DXライブラリ
- Windows

Unityなどのゲームエンジンを使用せず、ゲームループ、入力、描画、当たり判定、
カメラ、ステージデータ、エディターをC++とDXライブラリで実装しています。

## 実装上の工夫

### 重力反転

重力方向を列挙型で管理し、加速度、接地面、当たり判定、表示方向を切り替えています。
プレイヤーだけでなく、敵、重力ブロック、ボスにも個別の重力設定を持たせています。

### 高速移動時の当たり判定

弾や突進敵は、移動後の位置だけでなく移動前から移動後までの範囲を調べ、
1フレームで薄い壁を通り抜ける問題を防いでいます。

### カメラとループ穴

ステージ内に複数のカメラ範囲を設定でき、範囲切り替え時のみ補間します。
ループ穴による大きな座標移動と通常の追従を分け、画面が急変しにくい構成にしています。

### ステージエディター

ゲーム本体と同じデータ構造・描画処理を利用するエディターを実装しました。
ステージをテキスト形式で保存し、保存前に必須オブジェクト、配置数、座標、
穴の重複、ボス用カメラ範囲などを検証します。

## 操作

| 操作 | キーボード | コントローラー |
|---|---|---|
| 移動・照準 | 矢印キー | 左スティック／方向パッド |
| ジャンプ・決定 | Space / Enter | A |
| 射撃・戻る | Z / Esc | B |
| ダッシュ | Shift | X |
| 重力反転 | G | Y |
| レーザー | X | RB |
| ポーズ | P | START |

## ソースコードの確認方法

1. Visual Studio 2022の「C++によるデスクトップ開発」をインストールします。
2. DXライブラリを公式サイトから取得します。
3. `DxLibLocal.props.example`を`DxLibLocal.props`へコピーします。
4. `DxLibLocal.props`内のパスを、ローカルのDXライブラリ配置先へ変更します。
5. `GravityShift2/GravityShift2.sln`を開き、x64構成でビルドします。
